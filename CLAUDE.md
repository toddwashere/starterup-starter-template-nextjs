# Claude Code Guidance

Canonical project instructions for AI coding agents live in [`.ai/`](./.ai/).

Before handling environment variables, credentials, or setup context, read [`.ai/conventions/secrets-files.md`](./.ai/conventions/secrets-files.md). Never read local secret files such as `.env`; use [`.env.example`](./.env.example) as the only environment-variable reference.

For all other project conventions, start with [`AGENTS.md`](./AGENTS.md).
